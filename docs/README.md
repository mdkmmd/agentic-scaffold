# docs

The agent workspace. Three kinds of document, three folders.

| Folder | Answers | Lifetime |
|---|---|---|
| `guidelines/` | How do we work and code here? | Long-lived, rarely changes |
| `specs/` | What are we changing, and how do we prove it works? | One per feature, closed when done |
| `guides/` | How does this existing thing already work? | Kept only while true |

`guidelines/universal/` is identical in every project. `guidelines/project/` is
the only place project facts belong.

Start at the repo root `AGENTS.md`.
