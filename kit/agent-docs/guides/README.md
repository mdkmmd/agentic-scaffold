# Guides

Long-lived explanations that are not tied to one feature: data maps, plain English
walkthroughs of a screen, deployment notes, one-off SQL kept for reference.

A guide answers "how does this already work?". A spec answers "what are we changing?".

Naming: `topic-kind.md`, e.g. `simulator-data-map.md`, `release-2026-01-pricing.sql`.

Keep a guide only while it is true. A stale guide is worse than no guide; delete it.
