# agent-docs

The agent workspace. Personal and always gitignored. Start at the repo root `AGENTS.md`.

Scaffold version: 2

| Folder | Answers | Lifetime |
|---|---|---|
| `guidelines/universal/` | How do we work and code anywhere? | Copied as-is, never edited here |
| `guidelines/stacks/` | What is special about this stack? | Copied as-is, only stacks in use |
| `guidelines/project/` | What is true only in this project? | Filled in once, kept current |
| `specs/` | What are we changing, and how do we prove it works? | One per feature, closed when done |
| `guides/` | How does this existing thing already work? | Kept only while true |
| `memos/` | What should we revisit later? | Deleted when no longer useful |

`guidelines/project/` is the only place project facts belong.
